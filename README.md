# Walmart Sales Data Analysis Dashboard

## Project Overview
This project analyzes Walmart sales data using Python, Pandas, Jupyter Notebook, and Power BI.

## Tools Used
- Python
- Pandas
- Matplotlib
- Jupyter Notebook
- Power BI

## Key Insights
- Total Sales: 6.74 Billion
- Total Stores: 45
- Average Weekly Sales: 1.05 Million
- Top Performing Stores Identified
- Sales Trend Analysis
- Fuel Price, CPI, and Unemployment Impact Analysis
